## Hackathon 进入判断

当前判断：可以直接进入 Hackathon。

最低进入条件已经满足：

- 有明确项目：`Citely`。
- 有明确赛道：Cobo / Agentic Commerce。
- 有目标用户：专业作者、付费读者、AI Agent。
- 有最小闭环：Agent 发现文章 -> 命中 402 -> 用 CAW / x402 支付 USDC -> 解锁全文 -> 返回作者与 EAS 出处。
- 有 repo skeleton / proposal / scope / risk / 技术验证材料。
- 已完成组队或角色确认。

进入 Hackathon 后的主线应该从“继续写概念”切换为“跑通最小可演示链路”：

1. 先保证 `GET /api/v1/articles` 和单篇 `read` 路径可演示。
2. 让未付款访问稳定返回 402。
3. 让付款成功后返回全文、作者、EAS / receipt 证明。
4. 用 CAW / Pact 或 mock policy 展示预算和权限边界。
5. 把失败路径、人工确认点、fallback 写进 README。
