## 今日学习：AI 基础（复习笔记）

### 1. LLM（大型语言模型）

**核心认知：**
- LLM 是概率模型，不是数据库，也不是真理来源
- 输出是候选结果，不是事实本身
- 模型能力是推理入口，不是最终验证

**关键知识点：**
- Token：模型处理的基本单元，影响上下文容量和调用成本
- Embedding：将文本映射为向量，衡量语义相似性，但不判断正确性
- Hallucination：模型生成看似合理但不正确的内容

**第一性原理：**
- 把模型当作推理层，不是真理来源
- 模型输出应转为可检查的对象（schema、参数、引用、日志）

### 2. Prompt Engineering（提示工程）

**核心认知：**
- Prompt 是你和模型之间的接口设计，不只是"怎么问 AI"
- 好的 Prompt 不让模型更自信，而是让模型在正确的地方停下来

**关键知识点：**
- Instruction：角色定义、任务目标、边界、不确定信息处理、输出格式
- Few-shot：在 prompt 中加入少量示例
- Structured Output：用 JSON schema 返回固定结构，方便代码验证
- Prompt Injection：恶意输入导致模型忽略原规则

**安全原则：**
- Prompt 是软约束，不是安全边界
- 高风险操作必须代码级验证

### 3. Context Management（上下文管理）

**核心认知：**
- 模型基于它看到的上下文行动
- 上下文是信息治理问题，不是简单拼接文本

**关键知识点：**
- Context Window：单次请求最大上下文量
- Context Engineering：数据源选择、排序、裁剪、来源标注
- Memory：跨请求保留用户偏好、历史，有身份/权限假设风险

### 4. RAG（检索增强生成）

**核心认知：**
- RAG 的可靠性取决于证据链，不只是向量数据库
- 检索结果 = 候选证据 ≠ 事实

**关键知识点：**
- Chunking：将长文档分割成可检索的片段
- Vector DB：基于相似性检索，需存储元数据
- Citation：将答案链接回原始来源

### 5. AI Agent（AI 代理）

**核心认知：**
- Agent 是能持续调用工具、读取状态、调整步骤以达成目标的系统
- 核心是在有限权限和可审计流程中执行动作

**安全架构（AI × Web3）：**
1. 用户定义目标和约束
2. Agent 读取上下文生成计划
3. 系统拆分只读和候选写入步骤
4. 高风险操作用户确认 + 钱包执行
5. 每一步记录日志

### 6. Frameworks（AI 框架）

| 框架 | 特点 |
|------|------|
| LangChain | 最常见的 LLM 开发框架 |
| LangGraph | 多工具调用、长时运行、状态机 |
| DSPy | 将 prompt 写成可优化程序 |
| OpenAI Agents SDK | 含工具、交接、防护、追踪 |

### 7. MCP（模型上下文协议）

- 标准化模型与外部工具、数据源的连接方式
- 不替代账户权限、交易模拟、签名确认

### 8. Evaluation（评估）

- 把"感觉效果不错"变成"系统可持续改进"
- Golden Set：覆盖常见问题、边界问题、高风险问题
- Regression：防止旧问题复发
- AI × Web3 特殊要求：交易解析准确性、风险提示漏报、Prompt Injection 识别
