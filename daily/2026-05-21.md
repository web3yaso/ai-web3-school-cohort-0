# Daily Note: 2026-05-21

## 今日学习：AI x Web3 School：Web3运行原理

核心的 takeaway

* Web3 不是一个前端产品，而是一套多层系统。

* 钱包是用户入口，但真正把请求送到链上的是 RPC 和节点网络。

* validator 通过质押和共识机制维护链的安全。

* 智能合约“不可篡改”，但项目可以通过 proxy 架构实现“可升级”。

* 理解 Web3 要从一笔交易的生命周期开始，而不是从一堆名词开始。

我觉得这场分享最有价值的部分不是 PPT，而是 Q&A，因为问题都很真实：

问题一：validator 质押 32 ETH 后，奖励到底怎么来？
这说明新手开始从“节点是什么”进入到“经济激励如何维持安全”。

问题二：合约不可篡改，为什么还能升级？
这是理解 DeFi、安全审计、协议治理必须跨过的一关。

问题三：RPC 节点到底存什么、怎么服务用户？
这关系到钱包体验、节点服务商、链上数据访问和基础设施商业模式。

问题四：节点之间怎么发现彼此？
这是理解去中心化网络底层结构的关键。

## 核心收获

- 一笔交易从签名到链上可见：钱包→RPC→mempool→区块→共识→执行→确认→索引→浏览器
- 私钥 = 控制权，签名 = 授权证明，助记词 = 高风险秘密
- Agent Wallet 核心：控制权不交给概率系统，Agent 只有可验证、可限制、可撤销的行动空间
- Web3 工具：读写分离，工具用确定性边界限制模型
- Agent Workflow 要把目标、上下文、计划、模拟、确认、执行和 trace 拆成可恢复的步骤
