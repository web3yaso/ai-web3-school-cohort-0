# Daily Note: 2026-05-23

## 今日学习：AI x open agentic economy

这次分享的主题围绕 Open Agentic Economy，也就是在 AI Agent 逐渐成为互联网新参与者之后，Ethereum 如何为人类和 Agent 共同参与的开放经济提供基础设施。主持人开场提到主题大致是从 ERC-404 / ERC-A1A3 等方向切入，探索构建开放 Agentic Economy 的路径。

### Ethereum for AI，本质上是 Ethereum for Humans

Sophia 的核心论点是：Ethereum for AI really means Ethereum for humans。也就是说，大家讨论 AI Agent、自动化交易、Agent 经济时，不能只把重点放在“让 AI 能做什么”，更重要的是：这些系统最终要服务人类，帮助人类更好地协作、交易、验证、表达信任与所有权。

换句话说，Ethereum 不是单纯给 AI Agent 提供一个支付层或账户层，而是提供一个开放、可验证、可组合的社会经济基础设施。

### Agentic Economy 需要开放协议，而不是封闭平台

这次分享背后的大方向是：未来 AI Agent 会越来越多地参与信息获取、任务执行、支付、身份验证和协作。如果这些 Agent 都运行在封闭平台里，那么新的互联网经济仍然会被少数平台控制。

Ethereum 的价值在于，它可以为 Agent 经济提供一个开放底层，让身份、资产、权限、支付、声誉和协作关系不完全依赖中心化平台。

这对你之前关注的 Agent Open Information Platform / RSS for Agents / x402 广告分发 很有启发：未来不只是“人读内容”，而是 Agent 也会读取、引用、订阅、支付和调用内容节点。

### CROPS 是理解 Ethereum × AI 的一个框架

现场有人问 Sophia 解释 CROPS。CROPS 指的是：

>>> Censorship Resistant, Open Source, Private, Secure 抗审查、开源、隐私、安全。

CROPS	对 Ethereum 的意义	对 AI Agent 经济的意义
Censorship Resistant	不被单点控制	Agent 能访问开放经济网络
Open Source	可检查、可复用	Agent 行为与基础设施更透明
Private	保护用户自主权	用户 intent 不被平台完全收割
Secure	保护资产和系统	Agent 执行交易时有安全边界
