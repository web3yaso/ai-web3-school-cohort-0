# Daily Note: 2026-05-22

## 今日学习：AI x Web3 School：AI下乡计划

这期分享讨论了 AI 与 Web3 的结合方向。一个核心观点是：AI + Web3 不是简单地把所有东西都放到链上，而是要找到 AI Agent 能提升效率、Web3 能提供资产与结算能力的场景。

在稳定币方向，分享中提到，稳定币的经济属性不会因为 Agent 出现而改变，但 Agent 可以让稳定币更方便地被使用，比如自动支付、自动结算、自动执行链上任务。未来，稳定币可能成为 Agent Economy 里的重要支付基础设施。

同时，token 与稳定币的结合也值得探索：稳定币负责稳定计价和支付，token 可以承担激励、权限、治理或生态协作功能。

最后，判断一个 AI Web3 工具是否有价值，不能只看它是否用了 AI 或 Web3，而要看它在具体场景里是否真正解决问题。一个好的 AI Web3 产品，应该让用户完成原本更复杂、更低效或更难验证的任务。
