# AI x Web3 School - Personal Learning Journal

## 关于

这是我在 AI x Web3 School 的个人学习仓库，用于记录每日学习笔记、任务进度、实验代码、Hackathon 项目实践、打卡草稿和 Handbook feedback。

这个仓库的目标不是替代 WCB 平台提交，而是沉淀公开、可索引、可复盘的 proof-of-work。

## 固定链接

- **Handbook**: https://aiweb3.school/zh/handbook/
- **WCB 课程页面**: https://web3career.build/zh/programs/AI-Web3-School
- **WCB Learning 页面**: https://web3career.build/zh/programs/AI-Web3-School#tab=learning
- **Learning Agent Prompt**: https://aiweb3.school/learning-agent.zh.txt

## 目录说明

- `daily/` - 每日学习笔记、打卡草稿和提交记录
- `tasks/` - 课程任务笔记
- `experiments/` - 小实验和代码片段
- `handbook-feedback/` - Handbook 问题、卡点、错别字和结构建议
- `hackathon/` - Hackathon 方向、项目定义、demo 设计和复盘
- `submissions/` - WCB / 打卡平台 / GitHub / Demo 提交记录
- `templates/` - 日记、任务和反馈模板

## 隐私提醒

本仓库默认为 public 仓库。请勿存放 API Key、助记词、私钥、验证码、未公开联系方式、内部会议链接或他人个人数据。

WCB Agent API key 只应放在本地环境变量中，例如 `WCB_AGENT_SECRET_API_KEY`，不要写进仓库、prompt 或聊天记录。

## 每日工作流

1. 以 UTC+8 确认今日日期，daily 文件名使用 `daily/YYYY-MM-DD.md`。
2. 打开 WCB Learning 页面确认今日课程、任务、会议和打卡入口。
3. 阅读 Handbook 相关章节，按最小路径、推荐路径、挑战路径选择当日任务。
4. 在当天的 daily note 记录学习、卡点、实验和打卡草稿。
5. 手动把打卡草稿提交到 WCB / 打卡平台。
6. 提交后把链接或截图说明写回 daily note。

## Handbook Feedback 工作流

1. 学习时发现问题，先写入 `handbook-feedback/`。
2. 每条 feedback 尽量包含：Handbook 页面链接、问题描述、建议改法、来源和优先级。
3. 如果后续要提交给 Handbook 上游，再把本仓库中的 feedback 整理成 issue 或 PR。
